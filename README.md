# سند (Sanad) — مساحتك الآمنة لتخفيف الضغط، بلهجتك

تطبيق أندرويد مبني بـ Flutter يساعد الشباب الليبي (18 سنة فأكثر) على اكتشاف الضغط النفسي مبكراً. يكتب المستخدم أو يتحدث بصوته عن يومه باللهجة الليبية، فيحلل الذكاء الاصطناعي مستوى الضغط ومصدره، ويقترح خطوة مناسبة: تمرين تهدئة، أو رسالة جاهزة للحديث مع شخص يثق به («كيف نقولها؟»)، أو توجيه فوري لجهات الدعم عند أي مؤشر خطر. وتعرض لوحة «نبض» للجامعات والجهات أرقاماً مجمّعة مجهولة الهوية فقط.

> مشروع فريق سند في الكوداثون الوطني — ملتقى ليبيا للذكاء الاصطناعي Ai4LY 2026.
> سند أداة دعم وتوجيه، **وليس تشخيصاً طبياً** ولا بديلاً عن المختص.

## المعمارية

```
 ┌────────────────────────── تطبيق Flutter (أندرويد) ──────────────────────────┐
 │  واجهات: الترحيب · يومي · النتيجة · كيف نقولها؟ · التمارين · الدعم · نبض        │
 │                                                                              │
 │  Safety (فحص محلي للخطر) ──► GeminiService ──► StoreService / PulseAuth     │
 └──────────────┬─────────────────────┬───────────────────────┬────────────────┘
                │                     │                       │
        App Check (Play Integrity)    │                       │
                ▼                     ▼                       ▼
      Firebase AI Logic ──► Gemini   Cloud Firestore     Firebase Authentication
      (تحليل + صياغة + صوت)          checkins (أرقام       (حسابات الجهات فقط)
                                     مجهولة) · institutions
```

- **بدون خادم خاص:** الاتصال بـ Gemini عبر Firebase AI Logic مباشرة من التطبيق، ومفتاح النموذج لا يُخزَّن في الكود؛ الحماية عبر App Check.
- **تدفق التحليل:** النص ← فحص الخطر المحلي (إن وُجدت عبارة صريحة تُفتح شاشة الطوارئ فوراً) ← حذف الأرقام والبريد من النص ← Gemini بمخطط JSON ثابت ← النتيجة ← حفظ سجل مجهول (المستوى، المصدر، الفئة، العمر، المدينة، الجامعة، التاريخ).
- **نموذج احتياطي:** إذا لم يرد النموذج الرئيسي خلال 15 ثانية يُستخدم نموذج أخف تلقائياً.

```
    safety.dart              # عبارات الخطر بمستويين

  screens/                   # كل الشاشات + المكونات المشتركة
assets/logo/                 # الشعار، شاشة البداية، الأيقونة
firestore.rules              # قواعد أمان Firestore
```

## متطلبات التشغيل

- Flutter 3.38 أو أحدث (Dart 3.10)
- Android Studio / Android SDK، وجهاز أندرويد 6.0 (API 23) أو أحدث
- مشروع Firebase مع: Firebase AI Logic (Gemini Developer API)، Cloud Firestore، Authentication (Email/Password)، App Check
- `flutterfire_cli` لتوليد `firebase_options.dart`

## خطوات الإعداد

1. استنساخ المستودع وتنزيل الحزم:
   ```bash
   git clone <repo-url> && cd sanad
   flutter pub get
   ```
2. ربط Firebase:
   ```bash
   dart pub global activate flutterfire_cli
   dart pub global run flutterfire_cli:flutterfire configure
   ```
3. في Firebase Console:
   - **AI Logic:** تفعيل Gemini Developer API.
   - **App Check:** تسجيل تطبيق أندرويد بمزوّد Play Integrity (مع بصمة SHA-256)، ولأجهزة التطوير إضافة رمز التطوير الذي يظهر في سجل التشغيل (Manage debug tokens).
   - **Firestore:** إنشاء قاعدة البيانات ونشر محتوى `firestore.rules`.
   - **Authentication:** تفعيل Email/Password لحسابات لوحة نبض.
4. إنشاء حساب جهة للوحة نبض: مستخدم في Authentication، ومستند في `institutions/{uid}` بالحقول:
   `name` (اسم الجهة)، `scope` (`all` أو `university` أو `city`)، `value` (رمز الجامعة أو المدينة، أو فارغ).
5. توليد شاشة البداية والأيقونة ثم التشغيل:
   ```bash
   dart run flutter_native_splash:create
   dart run flutter_launcher_icons
   flutter run
   ```
6. نسخة Google Play (اختياري): إنشاء مفتاح رفع، ونسخ `android/key.properties.example` إلى `android/key.properties` وتعبئته، ثم:
   ```bash
   flutter build appbundle --release
   ```
   ملفا `key.properties` و `*.jks` مستثنيان من المستودع ولا يُرفعان أبداً.

## الاستخدام

1. شاشة الترحيب: الموافقة على العمر والتنبيه، وأسئلة اختيارية بلا اسم.
2. «يومي»: اختيار المزاج والنوم، ثم الكتابة أو التسجيل الصوتي، ثم «حلّل يومي».
3. النتيجة: المستوى والمصدر والخطوة المقترحة؛ ومنها «كيف نقولها؟» أو التمرين أو الدعم.
4. «نبض»: من أيقونة الرسم البياني أعلى «يومي»، للجهات فقط بحساب.
